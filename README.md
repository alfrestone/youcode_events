# YouCode Events

Static website for YouCode events, built with plain HTML and CSS. No fancy frameworks, just good old-fashioned web basics. 

## What's inside?

*   **Home:** Hero section, upcoming events preview, and some cool stats.
*   **Events:** A full list of workshops, conferences, and hackathons.
*   **Speakers & Partners:** Meet the people running the events and the orgs backing them.
*   **Registration:** A simple form to sign up for events.

## How it's built

*   **HTML5** for structure
*   **CSS3** for styling (Flexbox/Grid)
*   No JavaScript, no build tools.
